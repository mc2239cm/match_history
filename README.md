# Battle Record CLI

対戦成績（自分・相手・先攻/後攻・勝敗）を記録・絞り込み表示し、Excel（`.xlsx`）形式で保存・読み込みできるコマンドラインツールです。

## 作った背景・目的

対戦の振り返りや勝率・先攻率の傾向把握をしたいとき、記録ツール側の入力が面倒だと継続しにくくなります。そこで、**素早く入力できて、あとから条件別に集計でき、誤操作でデータを失いにくい**シンプルなCLIツールとして作成しました。

WebやGUIではなくCLIとExcel（`.xlsx`）を選んだ理由は以下の通りです。
- ターミナルからキーボード操作のみでテンポよく記録・確認できるため
- 集計・共有しやすいExcel形式でデータを残せるため

## 主な機能と工夫

### 1. 入力コストを下げる記録機能（`RecordManager`）
- **履歴の番号呼び出し**：一度入力した「自分」「相手」を一覧表示し、番号で指定して再入力の手間を削減
- **柔軟な入力スタイル**：`自分, 相手, 先攻(1)/後攻(0), 勝敗(1)/敗北(0)` のカンマ区切り一括入力と、1項目ずつの逐次入力の両方に対応
- **途中終了**：入力途中でも `finish` を入力することで記録ループを終了可能
- **入力バリデーション**：要素数超過、範囲外の番号指定、先攻後攻・勝敗の `0/1` 以外の値をチェック

### 2. 条件別の絞り込みと指標算出（`ViewManager`）
- 自分・相手、勝ち・負け、先攻・後攻を組み合わせたフィルタリングに対応
- 絞り込み結果に応じて、試合数に加え、条件に依存しない指標（先攻率・勝率）を自動計算して表示

### 3. 誤操作・データ損失を防ぐファイル管理（`FileManager`）
- `openpyxl` を用いて `data/` ディレクトリ配下に `.xlsx` 形式で保存・読み込み
- 既存ファイルと名前が重複する場合の上書き確認、および `data_1.xlsx` のような連番ファイル名生成（`unique_filename`）に対応
- データ読み込み時の上書き確認や、終了時・読み込み前の未保存データ保存確認を実装

## 動作環境・セットアップ

- Python 3.x
- `openpyxl`

```bash
pip install openpyxl
python battle.py

```

## 使い方

起動するとメインメニューが表示されます。

```text
here are options
record: 1, view: 2, file(load): 3, end: 0
command:

```

* `1`（または `record`）：対戦成績を記録します。入力例：
* 一括入力：`DeckA, DeckB, 1, 1`
* 履歴番号を使った入力：`1, 2, 0, 1`
* 終了：`finish`


* `2`（または `view`）：記録一覧の表示と絞り込み・勝率/先攻率の確認を行います。
* `3`（または `load`）：`data/` フォルダ内の `.xlsx` ファイルを読み込みます。
* `0`（または `end`）：終了処理に進みます。

### 保存されるExcelフォーマット

1行目にヘッダーが出力され、2行目以降に記録が格納されます。

| You | Enemy | Fir(1)/Sec(0) | Win(1)/Lose(0) |
| --- | --- | --- | --- |
| DeckA | DeckB | 1 | 1 |

## 今後の改善点（既知の課題）

現状で把握している改善余地は以下の通りです。

* フィルタリング表示時の連番を、元データのインデックスではなく表示行の通し番号に揃えること
* Excel読み込み時に空行や想定外の列数の行が含まれる場合のバリデーション・例外処理の強化
